# AMJ Gebetstracker (WordPress)

WordPress-Plugin für den Gebetstracker von AMJ Nidda. Das Plugin liefert einen shortcode-basierten View für die Tablet-optimierte Erfassung der Besucherzahlen sowie ein Dashboard mit PDF-Export und speichert alle Einträge in einer eigenen Datenbanktabelle.

## Installation

1. Lade den kompletten Ordner in das Verzeichnis `wp-content/plugins/` deiner WordPress-Installation.
2. Aktiviere das Plugin **AMJ Gebetstracker** im WordPress-Backend.
3. Lege eine Seite an und füge den Shortcode `[amj_gebetstracker]` in den Inhalt ein.
4. Öffne die Seite im Frontend, um die Erfassung und das Dashboard zu nutzen.

## Funktionsumfang

- Altersgruppen: Atfal, Khuddam, Ansar
- Gebetszeiten mit Hervorhebung des aktuellen Gebets
- Erfassung der Besucher pro Gebet mit Speicherung in der Datenbank
- Dashboard mit Auswertung nach Tag, Woche oder Monat
- PDF-Export der Statistik
- Löschung der heutigen Einträge per Knopfdruck
